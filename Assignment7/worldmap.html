About This Project

This webpage demonstrates the use of HTML image maps and hyperlinks. Different regions of the world map are made clickable using the <area> element.

  • Circle: Used for Japan and United Kingdom.
  • Rectangle: Used for India, China and France.
  • Polygon: Used for countries/regions with irregular shapes.
  • Default: Opens general information about the world.
  • target="_blank": Opens information in a new browser tab.
  • alt: Describes each clickable region.
